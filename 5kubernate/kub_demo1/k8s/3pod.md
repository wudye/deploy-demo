1. Pod 是 Kubernetes 中最小的部署單位，是容器運行的基本環境。讓我詳細解釋：
   Pod = 容器 + 共享資源 + 網絡命名空間
   類比理解：
    Pod 就像一個虛擬機
    Container 就像虛擬機內的進程
    一個 Pod 可以包含多個容器，就像一個虛擬機可以運行多個進程
   ┌─────────────────────────────────────┐
   │              POD                    │
   ├─────────────────────────────────────┤
   │  ┌─────────────┐ ┌───────────────┐   │
   │  │  Container  │ │  Container   │   │
   │  │  (App)      │ │  (Sidecar)   │   │
   │  └─────────────┘ └───────────────┘   │
   ├─────────────────────────────────────┤
   │  Shared Network Namespace          │
   │  Shared Storage (Volumes)          │
   │  Shared IPC/PID Namespace         │
   └─────────────────────────────────────┘
2. Pod 的關鍵特性
    # 一個 Pod 中的所有容器共享：
    # - IP 地址
    # - Port 空間
    # - 網絡接口
    
    # 例如：主應用容器 (8080) + 日志代理容器 (9090)
    # 它們都有相同的 IP，不同端口
3. 用戶命令 → Deployment → ReplicaSet → Pod → Container
   Pod 是 Kubernetes 為解決大規模容器管理而設計的更高層抽象，而 Docker 是底層的容器運行時！
