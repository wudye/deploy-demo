核心区别总结
特性	单元测试	集成测试
测试范围	单个类/方法	多个组件交互
依赖管理	Mock 对象	真实 Bean
Spring 容器	❌ 不启动	✅ 启动
数据库	❌ Mock	✅ 真实或测试容器
执行速度	⚡ 快（毫秒级）	🐢 慢（秒级）
隔离性	✅ 完全隔离	⚠️ 部分隔离
复杂度	🟢 简单	🟠 中等
基类	AbstractBaseServiceTest	AbstractRestControllerTest

. 单元测试 (Unit Test)
定义
测试单个类或方法的逻辑，不依赖外部资源。

特点
特点	说明
🎯 聚焦	测试单个方法或类
🚀 快速	不启动框架，毫秒级执行
🔄 隔离	不依赖外部资源
🛠️ Mock	使用 Mock 对象模拟依赖
📝 简单	测试代码简洁
单元测试的依赖图
测试代码
    ↓
Mock Repository（模拟数据库）
    ↓
Mock RedisTemplate（模拟 Redis）
    ↓
Service（被测试）
    ↓
业务逻辑执行
关键点:

✅ 不连接真实数据库
✅ 不连接真实 Redis
✅ 不启动 Spring 容器
✅ 纯逻辑测试


 集成测试 (Integration Test)
定义
测试多个组件的交互，使用真实的依赖关系。

特点
特点	说明
🔗 集成	测试多个组件交互
🌐 真实	使用真实 Bean 和依赖
🐢 较慢	启动 Spring 上下文
📦 完整	测试完整的请求-响应流程
🔧 配置	需要配置测试环境
集成测试的依赖图
测试代码
    ↓
MockMvc（HTTP 模拟）
    ↓
DispatcherServlet（Spring MVC）
    ↓
Controller（Spring Bean）
    ↓
@MockitoBean（Mock Service）
    ↓
完整的 HTTP 请求-响应流程
关键点:

✅ 启动 Spring 容器
✅ 使用真实的 Spring MVC 流程
✅ 测试 HTTP 层
✅ Mock Service 但测试 Controller

测试金字塔
      E2E Tests
      (少量)
         /\
        /  \
       /    \
      /      \     Integration Tests
     /        \    (适量）
    /          \
   /            \
  /              \  Unit Tests
 /________________\ (大量）
推荐比例
测试类型	数量比例	执行频率
E2E 测试	5-10%	每次发布
集成测试	20-30%	每次提交
单元测试	60-75%	每次代码变更

决策树
需要测试的功能是什么？
    ↓
是否涉及 HTTP 请求？
    ├─ 是 → 使用集成测试
    │        - Controller 层
    │        - REST API
    │        - 请求/响应格式
    │
    └─ 否 → 需要测试业务逻辑吗？
              ├─ 是 → 使用单元测试
              │        - Service 层
              │        - 算法逻辑
              │        - 数据处理
              │
              └─ 否 → 可能需要纯 Java 测试
                       - DTO/Model
                       - Utility 类
具体场景
场景	测试类型	基类	原因
测试业务逻辑	单元测试	AbstractBaseServiceTest	只需 Mock 依赖
测试 HTTP API	集成测试	AbstractRestControllerTest	需要 MockMvc
测试数据库交互	集成测试	AbstractTestContainerConfiguration	需要测试容器
测试 DTO 转换	单元测试	无	纯 Java 对象
测试工具类	单元测试	无	无依赖

单元测试覆盖

1. 优先编写单元测试
// ✅ 推荐：大部分测试是单元测试
60-75% 单元测试
20-30% 集成测试
5-10% E2E 测试

快速反馈
易于调试
维护成本低
2. 关键路径使用集成测试
// ✅ 推荐：关键 API 路径使用集成测试

- 支付处理
- 订单创建
总结表
特性	单元测试	集成测试
测试范围	单个类/方法	多个组件
依赖	Mock 对象	真实 Bean
Spring 容器	❌ 不启动	✅ 启动
数据库	❌ Mock	✅ 真实/容器
Redis	❌ Mock	✅ 真实/容器
HTTP	❌ 不测试	✅ 测试
速度	⚡ 快（10-50 ms）	🐢 慢（2-5 秒）
基类	AbstractBaseServiceTest	AbstractRestControllerTest
比例	60-75%	20-30%
成本	🟢 低	🟠 中等
核心原则:

业务逻辑 → 单元测试
API 接口 → 集成测试
纯 Java 类 → 单元测试（或无基类）
快速反馈 → 优先单元测试
