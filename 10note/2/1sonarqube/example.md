🔵 SonarQube 是什么？
SonarQube 是一个开源的代码质量和代码安全分析平台。

📌 核心功能
1. 自动化代码质量分析
SonarQube 自动扫描代码，检测：

🐛 Bug - 潜在的错误和缺陷
🛡️ 安全漏洞 - 安全风险点
💨 代码异味 - 设计和实现问题
🔗 代码重复 - 重复的代码片段
📊 代码覆盖率 - 测试覆盖情况
2. 多语言支持
支持 25+ 编程语言：

Java
JavaScript/TypeScript
Python
C/C++
Go
PHP
C#
等等...
3. 质量标准评估
基于 ISO/IEC 25010 标准，评估代码：

可靠性 - 代码是否稳定可靠
安全性 - 是否存在安全风险
可维护性 - 代码是否易于维护
可测试性 - 代码是否易于测试
覆盖率 - 测试是否充分
🎯 SonarQube 解决的问题
问题 1：代码质量难以量化
传统方式：

"这段代码看起来不错..." ❌ 主观判断
"我觉得应该这样写..." ❌ 依赖个人经验
SonarQube 方式：

代码质量评分: A (92/100) ✅ 客观数据
代码覆盖率: 85% ✅ 精确数字
Bug 数量: 3 ✅ 具体数字
问题 2：代码审查效率低
传统方式：

人工逐行检查
容易漏掉问题
耗时且不统一
SonarQube 方式：

自动扫描分析
不遗漏问题
规则统一标准
问题 3：代码质量难以追踪
传统方式：

本周质量比上周好吗？ ❌ 不知道
哪个文件质量最差？ ❌ 不知道
代码质量在下降吗？ ❌ 不知道
SonarQube 方式：

质量趋势图：↑ 本周质量提升 5% ✅
最差文件列表：UserService.java ✅
历史对比：显示质量变化曲线 ✅
🏗️ SonarQube 架构
工作原理
你的代码
    ↓
SonarQube Scanner (扫描器)
    ↓
SonarQube Server (分析服务器)
    ↓
SonarQube Database (数据库)
    ↓
SonarQube Dashboard (可视化界面)
三大组件
组件	作用
SonarQube Server	Web UI、分析引擎、结果展示
SonarQube Scanner	扫描代码、收集指标、上传结果
Database	存储分析结果和历史数据
